【核心技术创新】

1. LLM 深度参与的条件生成 (v5.0 核心)
   
   4 层管线:
   L1 (参数骨架)
     └─ 从校准后验分布采样 p_know, p_learn 等
     └─ 确定性，可复现
   
   L2 (身份种子生成)
     └─ LLM 生成唯一的姓名、出生地、家庭结构
     └─ 高温度 T=0.9-1.1 最大化多样性
     └─ 核心创意价值在此
   
   L3 (规则派生 + LLM 叙事)
     └─ 数值派生: 成绩、体测、时间分配 (规则, 保证保真)
     └─ 叙事续写: 关键经历、兴趣、师生互动 (LLM, T=0.7)
   
   L4 (指纹校验与去重)
     └─ SHA256 身份指纹
     └─ Bloom Filter 20M 容量
     └─ 相似度检测 (Jaccard + Cosine)
     └─ 数学保证零重复

2. 可扩展到 20M+ 的唯一性保证
   
   三层去重机制:
   • Bloom Filter: 快速 O(1) 成员检测
   • 精确指纹集: 追踪已确认的重复
   • 相似度检测: 发现近似重复 (>0.85 阈值)
   
   处理策略:
   • 完全重复 → 重新生成
   • 近似重复 → LLM 改写差异化特征

3. 真实的 7×24 生命模拟
   
   5 场景时间预算守恒:
   场景1 - 学校: 8:00-12:00 (240 分钟) → 课堂学习
   场景2 - 社交: 12:00-13:00 (60 分钟) → 午餐 + 互动
   场景3 - 学校: 14:00-18:00 (240 分钟) → 下午课程
   场景4 - 课外班: 18:00-20:00 (120 分钟) → 40% 学生参加
   场景5 - 自学/休闲: 20:00-22:00 (120 分钟) → 作业 + 娱乐
   
   总计: 288 分钟/天 = 定值
   
   社交影响扩散:
   Δach_i = Σ_j (w_ij × (ach_j - ach_i) × susceptibility_i)
   
   事件半衰期衰减:
   impact(t) = impact_0 × 0.5^(t/half_life)
   例: 考砸事件 half_life=7 天，一周后影响减半

4. 关系动态演化
   
   8 种状态: acquaintance → friend → close_friend → 
             romantic_interest → dating (或) mentor
   
   自动转移规则:
   intensity > 0.5 && satisfaction > 0.6 → 升级关系
   days_since_interaction > 14 → 关系衰减
   conflict_count > 3 → 破裂
   
   持久化属性:
   • 强度 (0-1)
   • 满意度 (0-1)
   • 信任度 (0-1)
   • 冲突计数

【使用示例】

快速开始:

  cd c:\project\dachuang3
  pip install -r requirements.txt
  python scripts/w1_init.py
  python scripts/demo_quick.py

生成 500 学生 × 90 天仿真:

  from src.persona_service.student_generator import StudentGenerator
  from src.persona_service.teacher_parent_generator import TeacherGenerator, ParentGenerator
  from src.l_model.engine import LifeTimeEngineV2
  
  # 生成虚拟人口
  student_gen = StudentGenerator()
  students = [student_gen.generate_student(f"S{i:05d}", seed=1000+i)[0] for i in range(500)]
  teachers = [TeacherGenerator.generate_teacher(f"T{i:04d}", 10) for i in range(50)]
  parents = [ParentGenerator.generate_parent(f"P{i:05d}", f"S{i:05d}") for i in range(500)]
  
  # 运行仿真
  engine = LifeTimeEngineV2(students, teachers, parents, seed=42)
  result = engine.simulate(days=90)
  
  # 分析结果
  print(f"平均成绩: {np.mean([s['achievement_score'] for s in engine.students.values()]):.1f}")
